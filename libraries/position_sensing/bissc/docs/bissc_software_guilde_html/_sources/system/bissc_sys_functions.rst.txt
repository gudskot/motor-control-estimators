************************************************************
System-Level Functions
************************************************************

This section describes functions which act at the system-level.  This includes initialization of the C2000 device, start-up functions and interrupt service routine.  

Many of these functions make calls to the |PROTOCOL_NAME| Library which is described in :ref:`API Library Documentation <lnk-lib-top>`. 

System Initialization Functions
------------------------------------------------------------

.. _lnk-sys-init:

Most of the initialization function calls to driverlib or to functions generated by the system .syscfg file. The bissc_init() function leverages these plus performs some additional BiSS specific initializations.
