4. Limitations

Some features of BiSS-C have not been implemented in this communications demonstration. These features can be enabled by the system developer if required.

  1. Topologies other than point-to-point.

  2. Sequential (back-to-back) access to multiple registers. Single accesses are supported.

  3. Control data command frames (CTS = 0).

  4. The extension of the control-data frame by the slave. For example if the slave requires additional cycles to read or write to a register.

  5. Broadcast commands

  6. Some encoders require a higher current than the launchPad plus BOOSTXL_POSMGR can supply. If the encoder does not respond, or responds incorrectly, try providing power directly to the encoder from an external supply.
