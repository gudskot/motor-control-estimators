1. Overview

BiSS-C Encoder Interface by iC-Haus GmbH, is designed for serial transfer of digital data between linear, rotary or angle encoders, touch probes, accelerometers and the subsequent electronics, such as numerical controls, servo amplifiers and programmable logic controllers.

Note

BiSS is a trademark of iC-Haus GmbH. Developers must obtain their own BiSS license. Information can be found at biss-interface.com. For more details on the protocol and implementation aspects, see the BiSS-C Interface website.

The C2000 BiSS-C Encoder Interface Reference is divided into three parts:

  1. Hardware and overall design. This is described in C2000 BiSS-C Encoder Interface TI Design (TIDM-1010).

  2. Software: BiSS-C encoder interface Application Programming Interface (API)

  3. Software: System solution demonstration

This document focuses on the API and system example.

1.1. Application Programming Interface (API)

The API provides functions and definitions used to implement the encoder interface.

Key Features of the library:

  • Encoder interface integrated into a C2000 real-time microcontroller solution

  • Meets the encoder interface clocking requirements

  • Supports read and write of registers through the control data (CD) frame

  • Cyclic Redundancy Check (CRC) calculations

  • All source code is provided

1.2. System Example

Provides support functions to configure a C2000 Real-Time Control device to support BiSS-C.

Key Features:

  • Provides a blueprint for how to integrate the library into a project.

  • Processing to perform basic error checks, update multi-turn and single-turn position.

  • Example to read and write to registers through control data.

  • All source code is provided.

Note

For device-specific requirements, refer to the TIDM-1010 BiSS-C Encoder Interface design guide.
