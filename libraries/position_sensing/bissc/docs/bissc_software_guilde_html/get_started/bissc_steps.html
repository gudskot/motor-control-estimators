2. Getting Started Steps

The recommended sequence to get started is:

  1. Review and install the tools as described in the minimum requirements.

  2. Run the system example.

  3. If implementing your own system, refer to BiSS-C library integration.

  4. Obtain your development license. BiSS is a trademark of iC-Haus GmbH. Developers must obtain their own BiSS license. Information can be found at biss-interface.com. For more details on the protocol and implementation aspects, see the BiSS-C Interface website.
