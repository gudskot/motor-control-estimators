1. BiSS-C Library Integration

Reference the included System Example as a blueprint for integrating the library into an application. This section provides an overview of the steps required.

1.1. Resolve Resource Conflicts

  1. Review the resources used by the Encoder Interface. The resource utilization is described in TIDM-1010.

  2. Resolve any resource conflicts with your specific application. Include the CLB tiles, XBARS and GPIO pins in this evaluation. In some cases, a specific resource was used due to the LaunchPad pinout. Your own application may have different hardware requirements and limitations. For example, a specific CLB tile may be able to access a GPIO through a specific XBAR.

  3. Implement and test changes using the stand-alone example. The booster pack can be connected to a LaunchPad or ControlCard through wires to test the changes.

  4. Proceed with integration into your application.

1.1.1. SPI Instance

If you change the SPI instance make it matches in the following locations:

  1. System communication demo .syscfg file

  2. Library pm_bissc_include.h file

1.2. Add Header Files

Include the following header files in the project source:

  1. BiSS-C library header file: #include "pm_bissc_include.h"

  2. System functions header file: #include "bissc.h"

1.3. Update Code Composer Studio Search Locations

CCS searches specific locations for header files and the library (.lib) files. Referring to the directory structure and update the search locations by the following steps:

  1. In Code Composer Studio Project Explorer window: Right click project name

  2. Select: Properties -> Build -> C2000 Compiler Options -> Include Options

  3. Add the directory path for each include file to the compiler search path.

  4. Once again, Right click project name

  5. Select: Properties -> Build -> C2000 Linker -> File search Path.

  6. Include the library binary in the linker options. For example: pm_bissc_f28p65x.lib

  7. Add the directory path for the lib to the library search path.

1.4. Add System-Level Functions

The System Example includes functions which you may wish to include in your project. Depending on your specific needs, you can copy functions or include the source files from the example by following these steps:

  1. In Code Composer Studio: Right click project name

  2. Select: Add Files

  3. Select the file(s) to include.

1.5. Create Global Structures

These structures are documented in the the System Example.

The library requires global variables to share data between modules and with the system.

1.6. Initialize the System

Refer to the example system initialization functions. Some functions may require modification for your specific system. Check that the BISSC_FREQ_DIVIDER is correctly defined for your device CLB clock frequency. This is defined in the system bissc.h header file.

1.7. Implement Background Loop, SPI ISR

Use the provided system run-time functions as a template, implement the following functions:

End of single-cycle data interrupt (SPI RX ISR). Populate the RX data array with the content of the SPI RX FIFO.

Listing 1.5 SPI ISR: /boostxl_posmgr/shared/source/bissc.c
//
extern PM_bissc_scdStruct scdParams;
interrupt void bissc_spiRxISR(void)
{
    uint16_t i;
    for (i = 0; i < PM_BISSC_SPI_FIFO_MAX_LEVEL; i++)
    {
        scdRxData[i] = SPI_readDataNonBlocking(PM_BISSC_SPI)
                & scdParams.spiFIFOMask;
    }
    SPI_clearInterruptStatus(PM_BISSC_SPI, SPI_INT_RXFF_OVERFLOW);
    SPI_clearInterruptStatus(PM_BISSC_SPI, SPI_INT_RXFF);
    scdParams.dataReady = true;
    Interrupt_clearACKGroup(INTERRUPT_ACK_GROUP6);
}
//

1.8. Send MA and Receive Response

An example of the run-time flow is shown below. The library functions called are documented in the Library Public API section.

Listing 1.6 Run-time flow example: /solutions/boostxl_posmgr/shared/source/bissc.c
//
    uint16_t status;
    while(1)
    {
        //
        // Setup a single-cycle data transaction
        // Check if a command data frame has been parsed or can be initiated
        // Run the command data state-machine
        // Check for errors from the command-data state-machine
        //
        PM_bissc_setupSCDTransaction(scdParams);
        #if PM_BISSC_ENCODER_HAS_CD_INTERFACE
        bissc_setupCDTest(cdParams, registerParams);
        PM_bissc_doCDTasks(cdParams, registerParams);
        if(cdParams->cdState == PM_BISSC_CD_PARSED)
        {
            enum cdStatus cdStatus = cdParams->cdStatus;
                switch(cdStatus)
                {
                    case PM_BISSC_CD_READ_PASS:
                        bisscDiagnostics->cdReadPassCount++;
                        break;

                    case PM_BISSC_CD_WRITE_PASS:
                        bisscDiagnostics->cdWritePassCount++;
                        break;

                    case PM_BISSC_CD_WRITE_FAIL:
                        bisscDiagnostics->cdWriteFailCount++;
                        break;

                    case PM_BISSC_CD_CRC_FAIL:
                        bisscDiagnostics->cdCRCFailCount++;
                        break;

                    case PM_BISSC_CD_READ_WRITE_INVALID:
                        bisscDiagnostics->cdRWInvalidCount++;
                        break;

                    case PM_BISSC_CD_READ_WRITE_UNSUPPORTED:
                        bisscDiagnostics->cdRWUnsupportedCount++;
                        break;

                    default:
                        bisscDiagnostics->cdFailCount++;
                        break;
                }
        }
        #endif // end PM_BISSC_ENCODER_HAS_CD_INTERFACE

        //
        // Clearing the single-cycle data array is not required.
        // This is done to aid in debug.
        //
        memset((void *)scdRxData, 0, sizeof(scdRxData));

        //
        // Start the single-cycle data frame MA clock
        // Wait for the SPI to read the data
        // Parse the position, error and warning
        // Check for errors
        //
        PM_bissc_startOperation(scdParams, BISSC_FREQ_DIVIDER);
        while(scdParams->dataReady != true) {}

        status = PM_bissc_receivePosition(scdParams, cdParams, encoderInfo);
        if(status != PM_BISSC_PASS)
        {
            bisscDiagnostics->scdCRCFailCount++;
            //ESTOP0; // Halt PC on failure
        }
        else
        {
            bisscDiagnostics->scdPassCount++;
        }
        DEVICE_DELAY_US(BISSC_IDLE_DELAY_US);
    }
//
