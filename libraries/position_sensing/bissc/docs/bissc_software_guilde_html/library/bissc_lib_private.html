5. Library Private Functions

The following functions are not called directly by the application. They are called from other functions within the library.

void bissc_generateCRCTable(uint16_t nBits, uint16_t polynomial, uint16_t *pTable)

Generates CRC tables for a specified polynomial

This function generates table of 256 entries for a given CRC polynomial with specified number of bits (nBits) Generated tables are stored at the address specified by pTable.

Parameters

  • nBits – - Number of bits of the given polynomial

  • polynomial – - Polynomial used for CRC calculations

  • pTable – - Pointer to the CRC lookup table

Returns

None.

static void bissc_configureCLB(uint16_t spiClocks, uint16_t dataClocks) __attribute__((ramfunc))

Configure the CLB for a Transaction.

Configures the CLB counters and R0 register in order to generate the required number of MA clocks and SPI clocks for the transaction.

Parameters

  • spiClocks – The number of SPI clocks required to receive the single-cycle-data into the RX FIFO. This includes any additional clock cycles needed to trigger the SPI RX interrupt.

  • dataClocks – The number of MA clocks required to receive the single-cycle-data.

Returns

None.

static void bissc_configureSPILength(uint16_t widthFIFO, uint16_t depthFIFO) __attribute__((ramfunc))

Configure the SPI FIFO depth.

Configures the SPI RX FIFO width and depth as required for the transaction.

Note

The SPI TX FIFO is not used by BiSS-C

Parameters

  • widthFIFO – is the word length

  • depthFIFO – is the RX FIFO interrupt level

Returns

None.

static uint64_t bissc_getBits(uint16_t numBitsToFetch, uint16_t numBitsParsed, uint16_t bufferWidth) __attribute__((ramfunc))

Extract bits from the received data. 

//!
//! In the following examples:
//!   - Bits to be fetched are marked "A"
//!   - Bits already parsed are marked as "P"
//!   - "P*" intersection of baseElement with numBitsParsed marks the
//!     last bit previously parsed and the start of data bits to extract.
//!
//! Case 1:
//! The bits to fetch (A) are contained across elements.
//!
//! |<-------  width = n+1 ----->|
//!  n n-1 n-2 ...  4  3  2  1  0  <-- bit in element
//!
//!  x  x   x  ...  x  x  x  x  x
//!  A  A   A  ...  A  x  x  x  x   RxData[baseElement+numElements-1]
//!  A  A   A  ...  A  A  A  A  A   RxData[baseElement+numElements-2]
//!  ....
//!  A  A   A  ...  A  A  A  A  A   RxData[baseElement+1]
//!  P  P*  A  ...  A  A  A  A  A   RxData[baseElement]
//!     ^---numBitsParsed
//!  P  P   P  ...  P  P  P  P  P
//!  ....
//!  P  P   P  ...  P  P  P  P  P   RxData[0]
//!
//! Case 2:
//! The bits to fetch (A) are contained within one element.
//!
//! |<-------  width = n+1 ----->|
//!  n n-1 n-2 ...  4  3  2  1  0  <-- bit in element
//!
//!  x  x   x  ...  x  x  x  x  x
//!  P  P*  A  ...  A  A  A  A  x   RxData[baseElement]
//!     ^   <--bitsToFetch -->|
//!     |
//!     -----numBitsParsed
//!
//!
Attention

This function makes the following assumptions:

  • Data is right justified in the global array named scdRxData.

  • Data is ordered such that element 0 is the most-significant word

  • Fetching bits beyond the size of the array is not checked

Parameters

  • numBitsToFetch – Number of bits to extract and return.

  • numBitsParsed – How many bits were previously parsed. Corresponds to the starting place for bit extraction.

  • bufferWidth – Word size of the SPI FIFO that captured the data.

Returns

Bits extracted from the scdRxData array.

uint16_t bissc_getCRC(uint16_t crcStart, uint16_t nBitsPoly, uint16_t *msg, uint16_t *crcTable, uint16_t msgBytes) __attribute__((ramfunc))

Calculate a CRC using a lookup table.

Parameters

  • crcStart – Initial value. This is typically 0.

  • nBitsPoly – The number of bits in the polynomial

  • msg – A pointer to the data to calculate the CRC for

  • crcTable – A pointer to the CRC lookup table

  • msgBytes – The number of 8-bit bytes in the message. For example: If the message is 16-bits, then msgBytes is 2. If the message uses a partial byte then round up. For example: 18-bits then msgBytes = 3.

Returns

The calculated CRC value.

static void bissc_resetCLB(void) __attribute__((ramfunc))

Reset the CLB.

Reset portions of the CLB after a transaction or to recover from a failed transaction.

Returns

None.

static void bissc_setCDMBit(enum cdmValue value) __attribute__((ramfunc))

Set the CDM bit for the next SCD transaction. 

//

enum cdmValue
{
    PM_BISSC_SCD_CDM_ONE = 0U,      // CDM = 1
    PM_BISSC_SCD_CDM_ZERO = 1U,     // CDM = 0
    PM_BISSC_SCD_CDM_DEFAULT = 1U,  // CDM default = 0
};

//
The value is sent to the CLB tiles through the CLB’s GPREG.

Parameters

  • value – to be output during the BiSS timeout. The inverse of value is interpreted to be the CDM bit by the encoder.

Returns

None.
