2. Build and Run the Example

This example provides a roadmap for integration of the library into an application.

Note

For Code Composer Studio information, refer to the Code Composer Studio User’s Guide.

2.1. Hardware Connections

Setup the hardware as described in the TIDM-1010 design guide.

2.2. Import and Run Example Project

The system example directory, [MC_SDK_ROOT]/solutions/boostxl_posmgr/<device>, contains a Code Composer Studio projectspec file. To import the project into CCS, follow these steps:

  1. Install the minimum required tools. Refer to Minimum Requirements.

  2. Import the example system demonstration.

    1. In Code Composer Studio (CCS), click Project –> import CCS Projects..

    2. Navigate to the system example directory: [MC_SDK_ROOT]/solutions/boostxl_posmgr/<device>

    3. In the ccs/bissc/ directory, select the bissc_systemtest.projectspec file

    4. Click Finish.

    5. In the CCS Project Explorer you should now see the demo and library projects as shown in Fig. 2.1.

    Note

    When you import the system example, CCS will also import the associated library project.

    Fig. 2.1 Code Composer Studio Project Explorer Window.

  3. Select the build configuration of choice

    1. To select the build configuration: right-click on the project

    2. Select: build configurations and set active.

    3. Select the build configuration.

The build configurations are:

boostxl_posmgr_site2_RAM:

Builds the solution to load and run from RAM. The pin-out corresponds to the LaunchPad + BOOSTXL_POSMGR site2 as described in TIDM-1010 design guide.

boostxl_posmgr_site2_FLASH:

The solution loads the demo to flash. At run-time, critical portions are copied to execute from RAM.

  1. Select the active board configuration

    Note

    This step may or may not apply to your project. The image shown below is provided as an example only.

  1. Some projects may include two board configuration files (.ccxml) as shown in Fig. 2.2. This occurs when the LaunchPad and ControlCard use different JTAG connections.

  2. Right-click on the board configuration matching your hardware.

  3. Select Set as active target configuration

Fig. 2.2 Board Configurations

  1. Build the system example project

    1. In the project manager window, Right-click on the project name bissc_<device>_boostxl_comms_demo

    2. Select Rebuild Project

    3. Observe the console window for any errors or for successful completion of the build.

    4. Once the build completes, without errors, execute the project by selecting Run –> Debug

  2. Populate the expressions window

    1. Right-click on the expressions window

    2. Select import

    3. Browse to the location [SYS_ROOT]/shared/debug/

    4. Select the file bissc_vars.txt and click open

    5. At the top of the expressions window, enable continuous refresh as shown in Fig. 2.5.

    Fig. 2.3 Code Composer Studio Import Expressions.

    Fig. 2.4 Code Composer Studio Expressions Window.

    Fig. 2.5 Enable Continuous Refresh.

  3. Run the code

    1. Press the Run/Resume button

    2. Manually turn the shaft of the motor or encoder

    3. Monitor the signals and variables in the expressions window. These structures and arrays are described in the globals section.
