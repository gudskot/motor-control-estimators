3. System Test Structures and Arrays

The following variables are used by the system only for testing. Monitor these in the expressions window as shown in the System Example.

Listing 3.1 System test structure and array: /boostxl_posmgr/f28p65x/source/pm_bissc_main.c
//
//*****************************************************************************
//
// A circular buffer for register reads. Each read is performed after a write
// access. As provided the reads should alternate between 1, 3, and 5.
//
//*****************************************************************************
uint16_t bisscRegisterReadData[BISSC_READ_COUNT];

//*****************************************************************************
//
// Test structure to log pass/fail counts returned by the API
//
//
//*****************************************************************************
bissc_diagnosticsStruct bisscDiagnostics;
bissc_diagnosticsStruct_Handle bisscDiagnostics_handle = &bisscDiagnostics;

//

4. Library Structures and Arrays

The following structures and arrays interact with the library. They can be monitored in the expressions window as described in the System Example.

Listing 4.1 Global structures and arrays: /boostxl_posmgr/f28p65x/source/pm_bissc_main.c
//
//*****************************************************************************
//
// Array and structures required to interface with the library
//
//*****************************************************************************
volatile uint32_t scdRxData[BISSC_SPI_MAX_FIFO_LEVEL];

PM_bissc_cdStruct cdParams;
PM_bissc_cdStruct_Handle cdParams_handle = &cdParams;

PM_bissc_scdStruct scdParams;
PM_bissc_scdStruct_Handle scdParams_handle = &scdParams;

PM_bissc_registerStruct registerParams;
PM_bissc_registerStruct_Handle registerParams_handle = &registerParams;

PM_bissc_encoderStruct encoderInfo;
PM_bissc_encoderStruct_Handle encoderInfo_handle = &encoderInfo;

uint16_t bisscCRCtableSCD[PM_BISSC_SCD_CRCTABLE_SIZE];

#if defined(PM_BISSC_ENCODER_HAS_CD_INTERFACE)
uint16_t bisscCRCtableCD[PM_BISSC_CD_CRCTABLE_SIZE];
#endif

//

The definitions of these can be found in the Library Variables section.
