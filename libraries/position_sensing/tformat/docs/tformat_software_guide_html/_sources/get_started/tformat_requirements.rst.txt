Hardware
------------------------------------------------------------
The hardware required is documented in |TFORMAT_TIDM|_.  This includes:

* Supported C2000 LaunchPads
* C2000 device requirements
* The Position Manager BoosterPack (|PM_BP_SHORT_NAME|_)
* A T-Format encoder with an appropriate shielded cable.
