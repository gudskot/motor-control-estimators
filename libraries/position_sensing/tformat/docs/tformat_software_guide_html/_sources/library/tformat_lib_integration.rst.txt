************************************************************
T-Format Library Integration
************************************************************

.. _lnk-integration:

Reference the included System Example as a blueprint for integrating the library into an application.  This section provides an overview of the steps required. 

Resolve Resource Conflicts
-----------------------------------------------------------

Review the resources used by the |TFORMAT_LIB_SHORT_NAME|. The resource utilization is described in |TFORMAT_TIDM|_.

Resolve any resource conflicts with your specific application. Include the CLB tiles, XBARS and GPIO pins in this evaluation. In some cases, a specific resource was used due to the LaunchPad pinout.  Your own application may have different hardware requirements and limitations.  For example, a specific CLB tile may be able to access a GPIO through a specific XBAR. 

Add Header Files
-----------------------------------------------------------
Include the following header files in the project source:

#. T-Format library header file:  ``#include "pm_tformat_include.h"``   
#. System functions header file: ``#include "tformat.h"``

Update Code Composer Studio Search Locations
-----------------------------------------------------------
CCS searches specific locations for header files and the library (.lib) files.  Referring to the :ref:`directory structure <lnk-directory>` and update the search locations by the following steps:

#. In Code Composer Studio Project Explorer window: *Right click project name*
#. Select: *Properties -> Build -> C2000 Compiler Options -> Include Options*
#. Add the **directory path for each include file** to the compiler search path. 
#. Once again, *Right click project name*
#. Select: *Properties -> Build -> C2000 Linker -> File search Path*.
#. Include the library binary in the linker options. For example: ``pm_tformat_f28003x.lib``
#. Add the directory path for the lib to the library search path. 

Add System-Level Functions
-----------------------------------------------------------
The System Example includes functions which you may wish to include in your project. Depending on your specific needs, you can copy functions or include the source files from the example by following these steps: 

#. In Code Composer Studio: *Right click project name*
#. Select: *Add Files*
#. Select the file(s) to include.

Initialize the System
-----------------------------------------------------------
Refer to the example :ref:`system initialization functions <lnk-sys-init>`. Some functions may require modification for your specific system.  Check that the TFORMAT_FREQ_DIVIDER is correctly defined for your device CLB clock frequency.  This is defined in the system tformat.h header file.
