5.2. Root Directory¶

Default Location

5.3. System Example Directory Structure¶

The system reference example source is located in the following directory structure with respect to [MC_SDK_ROOT]/solutions/boostxl_posmgr/:

System Reference Directory

Contents

[SYS_ROOT]/ccs/tformat/

Code Composer Studio projectspec file

[SYS_ROOT]/shared/include/tformat*.h

System Header file. Shared between devices

[SYS_ROOT]/shared/source/tformat*.c

System source code. Shared between devices

[SYS_ROOT]/shared/debug/tformat_vars.txt

CCS expressions import file.

[SYS_ROOT]/<device>/cmd

Linker command file. Device specific

[SYS_ROOT]/<device>/source/*tformat*.c

C28x C-source files. Device specific

[SYS_ROOT]/<device>/source/tformat*.syscfg

Device-specific pin-Mux and XBAR, CLB interconnect

5.4. Library Directory Structure¶

The API source is located in the following directory structure with respect to [MC_SDK_ROOT]/libraries/position_sensing/tformat:

API Library Reference

Contents

[API_ROOT]/ccs/<device>

Code Composer Studio projectspec file

[API_ROOT]/include

Header files

[API_ROOT]/source/pm_tformat_source.c

C28x BiSS-C communication C-source code

[API_ROOT]/source/pm_tformat_crc.c

C28x CRC C-source code

[API_ROOT]/source/pm_tformat_crc_vcrc.asm

VCRC module CRC assembly source code

[API_ROOT]/source/pm_tformat<device>.syscfg

CLB Tool: tile configuration. Device specific.

[API_ROOT]/lib/pm_tformat_<device>.lib

Device-specific binary
