1. Overview¶

T-Format Encoder Interface by Tamagawa Seiki, is designed for serial transfer of digital data between linear, rotary or angle encoders, touch probes, accelerometers and the subsequent electronics, such as numerical controls, servo amplifiers and programmable logic controllers.

For more details on the protocol and implementation aspects, see the Tamagawa Seiki website.

The C2000 T-Format Encoder Interface Reference is divided into three parts:

  1. Hardware and overall design. This is described in C2000 T-Format Encoder Interface TI Design (TIDM-1011).

  2. Software: T-Format encoder interface Application Programming Interface (API)

  3. Software: System solution demonstration

This document focuses on the T-Format API and system example.

1.1. T-Format API¶

The T-Format API provides functions and definitions used to implement the T-Format encoder interface.

Key Features of the library:

  • Encoder interface integrated into a C2000 real-time microcontroller solution

  • Meets the encoder interface clocking requirements

  • Supports all T-Format commands

  • Cyclic Redundancy Check (CRC) calculations

  • All source code is provided

1.2. System Example¶

Provides support functions to configure a C2000 Real-Time Control device to support T-format.

Key Features:

  • Provides a blueprint for how to integrate the library into a project

  • Command processing to perform basic error checks, update position, turns and encoder ID.

  • All source code is provided.

Note

For device-specific requirements, refer to the TIDM-1011 T-Format Encoder Interface design guide.
