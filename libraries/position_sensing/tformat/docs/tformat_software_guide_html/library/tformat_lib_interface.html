4. T-Format Encoder Interface API¶

This section describes the T-Format Encoder Interface Application Programming Interface (API). Usage of these functions are demonstrated by the system example.

4.1. Initialization API¶

The following functions initialize the system.

void PM_tformat_generateCRCTable(uint16_t nBits, uint16_t polynomial, uint16_t *pTable)¶

Initialize the CRC Lookup Table.

Generate a look-up table of 256 entries for a given CRC polynomial with specified number of bits. This table is only used if the C28x generates a CRC.

Note

This function is used if the C28x generates either the transmit or receive CRC. It is not used if the CLB generates a RX CRC or if the VCRC module generates a TX CRC. This behavior is controlled by the defines in the library header file.

Parameters

  • nBits – number of bits of the given polynomial

  • polynomial – polynomial used for the CRC calculations

  • pTable – pointer to the CRC table

Returns

None.

void PM_tformat_setupPeriph()¶

Initialize the CLB tiles and SPI module.

The CLB input MUX was configured earlier in the system-level XBAR configuration.

Returns

none

void PM_tformat_setFreq(uint32_t freqDiv)¶

Scale to generate T-format clock.

This function configures the CLB counters in order to generate a T-format clock at 400ns (2.5 MHz frequency).

Parameters

  • freqDiv – Specified as TFORMAT_FREQ_DIVIDER in the tformat.h

Returns

none

4.2. Run-time API¶

An example of the runtime flow is shown below:

Listing 4.1 /solutions/boostxl_posmgr/shared/source/tformat.c¶
        //
        // 1) Setup the command
        // 2) Start the operation (transmission)
        // 3) Wait for the response to be received by the SPI.
        //    The SPI RX FIFO ISR will set the dataReady flag.
        // 4) Unpack, or receive, the data.
        // 5) System specific: check and respond to errors
        // 6) Update any encoder parameters (position, turns, ID)
        //
        PM_tformat_setupCommandReadoutOrReset(PM_TFORMAT_ID0,
                                PM_TFORMAT_RX_CLOCKS_ID0,
                                PM_TFORMAT_RX_FIELDS_ID0,
                                PM_TFORMAT_TX_CLOCKS_ID0,
                                PM_TFORMAT_FIFO_LEVEL_ID0);
        PM_tformat_startOperation();
        while(tformatData.dataReady != true) {}
        PM_tformat_receiveDataID0_1_7_8_C();
        if(tformat_checkError(PM_TFORMAT_CFID0) != PM_TFORMAT_PASS)
        {
            ESTOP0;
        }
        encoderData.position =
                PM_tformat_updatePositionOrTurns(tformatData.dataField0,
                                                 tformatData.dataField1,
                                                 tformatData.dataField2);
        //

4.2.1. Setup and Send Command¶

The following functions are called during run-time to setup and start a command transmission.

void PM_tformat_setupCommandReadoutOrReset(enum commandID0_1_2_3_7_8_C, uint16_t tformatRXClocks, uint16_t tformatRXFields, uint16_t tformatTXClocks, uint16_t tformatFIFOLevel) __attribute__((ramfunc))¶

Setup a Data Readout or Reset Command.

This function:

  • Loads the PM_TFORMAT_SPI TX FIFO with the command field

  • Configures the SPI and CLB to send the command and receive the response.

  • Sets the global variable tformatData.dataReady to false.

See

For read or write of EEPROM use:

  • PM_tformat_setupCommandReadEEPROM

  • PM_tformat_setupCommandWriteEEPROM

Note

  • This function is valid for data readout commands (ID0, 1, 2) and for reset commands (ID7, 8 and C).

  • This function not valid for an EEPROM read (IDD) or EEPROM write (ID6).

Parameters

  • commandID0_1_2_3_7_8_C – Command to be sent PM_TFORMAT_IDx

  • tformatRXClocks – PM_TFORMAT_RX_CLOCKS_IDx SPI clocks required to send the request

  • tformatRXFields – PM_TFORMAT_RX_FIELDS_IDx Number of fields in the response

  • tformatTXClocks – PM_TFORMAT_TX_CLOCKS_IDx SPI clocks required to receive the response

  • tformatFIFOLevel – PM_TFORMAT_FIFO_LEVEL_IDx FIFO level required to send the request and receive the response

Returns

None.

void PM_tformat_setupCommandReadEEPROM(uint16_t eepromAddr) __attribute__((ramfunc))¶

Setup the Command for an EEPROM Read.

This function:

  • Loads the PM_TFORMAT_SPI TX FIFO with the fields required to read the encoder’s EEPROM.

  • Configures the SPI and CLB to send the command and receive the response

  • Sets the global variable tformatData.dataReady to false.

Parameters

  • eepromAddr – Address to be read

Returns

None.

void PM_tformat_setupCommandWriteEEPROM(uint16_t eepromAddr, uint16_t eepromData) __attribute__((ramfunc))¶

Setup the Command for an EEPROM Write.

This function:

  • Loads the PM_TFORMAT_SPI TX FIFO with the fields required to write to the encoder’s EEPROM.

  • Configures the SPI and CLB to send the command and receive the response.

  • Sets the global variable tformatData.dataReady to false.

Parameters

  • eepromAddr – Address to be written to

  • eepromData – Data to write

Returns

None.

void PM_tformat_startOperation(void)¶

Start the T-Format Transaction.

This function starts the transmission of the request.

See

This function is called after the appropriate setupCommand function:

  • PM_tformat_setupCommandReadEEPROM

  • PM_tformat_setupCommandWriteEEPROM

  • PM_tformat_setupCommand

Returns

none

4.2.2. Retrieve Response¶

The following functions retrieve and parse the encoder’s response.

void PM_tformat_receiveDataID0_1_7_8_C(void) __attribute__((ramfunc))¶

Receive Data for ID0, ID1, ID7, ID8 or IDC.

Call this function when tformatData.dataReady is true indicating the data is ready in the tformatRxData array.

This function parses the tformatRxData array to populate the following tformatData structure members with the received data:

  • controlField

  • statusField

  • dataField0, dataField1, and dataField2

  • crcField

The tformatData.crcCheck variable is populated with the calculated CRC of the received data. This can be used for error checking against the received crcField.

See

Other recieveData functions are:

  • PM_tformat_receiveDataID2()

  • PM_tformat_receiveDataID3()

  • PM_tformat_receiveDataIDD()

  • PM_tformat_receiveDataID6()

Note

  • This function is valid for requests ID0, 1, 7, 8 and C only.

  • For convenience, the library header file includes aliases to allow this function to be called using the format: PM_tformat_receiveDataIDx where x is 0, 1, 7, 8 or C.

  • This function does not clear unused members of the tformatData structure. This is an optional step the calling application can take if desired.

  • It is the responsibility of the calling application to perform error checking of the data.

Returns

none

4.2.3. Update Encoder Parameters¶

The following functions used to update the encoderData parameters.

uint32_t PM_tformat_updatePositionOrTurns(uint16_t field0, uint16_t field1, uint16_t field2) __attribute__((ramfunc))¶

Update the position or turns.

Inverts the received bit sequence for the actual position and turns data Refer to the T-format specification for which command fields contain position or turn information.

Parameters

  • field0 – first field received

  • field1 – second field received

  • field2 – third field received

Returns

32-bit position or turns

uint16_t PM_tformat_updateEncoderID(uint16_t enidField) __attribute__((ramfunc))¶

Update the encoder ID.

Inverts the received bit sequence of ENID to form the actual encoder ID Refer to the T-format specification for which command fields contain encoder ID (ENID) information.

Parameters

  • enidField – ENID field received from the encoder

Returns

16-bit encoderID
